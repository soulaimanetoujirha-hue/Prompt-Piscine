# Exercise 2: Applied Prompting for a Real Task

Task chosen: a 3-sentence professional summary for a fictional candidate (no real personal data used).

## Prompt A
> Write a 3-sentence professional summary for a backend developer skilled in Go and SQL, for a portfolio site.

**Output A:**

A backend developer with a strong focus on performance and reliability, specializing in Go and SQL-driven systems. Experienced in designing efficient database schemas and building APIs that scale under load. Passionate about writing clean, maintainable code and solving problems at the infrastructure level.

## Prompt B (one detail changed: role → frontend, skills → React/TypeScript)
> Write a 3-sentence professional summary for a frontend developer skilled in React and TypeScript, for a portfolio site.

**Output B:**

A frontend developer focused on building fast, accessible interfaces with React and TypeScript. Skilled at turning design concepts into responsive, production-ready components. Enjoys the intersection of good UX and clean, type-safe code.

## Comparison
Same structure and length both times, but the vocabulary and focus shift completely to match the role — the prompt is doing the work, not the model guessing.

## One sentence
Yes, both outputs clearly reflected the details I gave them, and with light editing (trimming a bit of the buzzword-y tone) I'd actually use either one.
