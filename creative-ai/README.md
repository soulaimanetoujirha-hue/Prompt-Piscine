# creative-ai

Quest: practice prompting a model for creative generation (text + images), then apply the same skill to a real professional task.

## Files
- `ex01_generate.md` — a simple prompt vs. a constrained one, same idea
- `ex02_applied.md` — a real professional use case (fictional persona, no personal data)
- `ex03_image.md` — vague vs. detailed image prompt

## What I learned

One sentence on how detail changed my results: adding constraints (length, tone, POV, style, camera angle) turned generic, guess-what-I-mean outputs into focused, usable ones — specificity is basically the whole trick.

One applied use I'd actually use prompting for: generating first-draft project descriptions and README summaries for my own repos, then editing them down myself.
