# Exercise 1: Get Structured JSON

## Prompt used
Return only JSON: {"language": string, "typed": boolean}

## Output
{"language": "en", "typed": true}

## Valid JSON?
Yes, confirmed with a JSON parser / no syntax errors.

## Why does a program need JSON instead of a sentence?
A program can parse JSON directly into variables without writing fragile text-parsing logic to extract meaning from a sentence.
